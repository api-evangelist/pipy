# Pipy (pipy)
Pipy is a high-performance, programmable network proxy designed for cloud, edge, and IoT environments. Written in C++ with an embedded JavaScript engine (PipyJS), it provides a small footprint, broad CPU architecture support, and a modular filter-based architecture for protocol conversion, traffic recording, message signing, and other networking tasks. Pipy is developed by Flomesh.

## APIs

### Pipy Admin API
Pipy exposes an Admin UI and administrative interface, accessible via the built-in repo-mode HTTP server (default port 6060). The administrative surface allows operators to manage Pipy repositories, configurations, and programmable filter chains written in PipyJS.

**Human URL:** [https://flomesh.io/pipy/docs/reference/api](https://flomesh.io/pipy/docs/reference/api)
