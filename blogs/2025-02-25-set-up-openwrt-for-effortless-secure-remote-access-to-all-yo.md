<h3>Set Up OpenWRT for Effortless, Secure Remote Access to All Your Devices — No VPN Needed</h3><p>Integrating Flomesh ZTM with OpenWRT routers enhances network security and functionality, enabling secure access to internal services without the complexity of traditional VPNs or firewall setups.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*eWlQ6l6KEfGFV-csACthUg.png" /></figure><p><a href="https://github.com/flomesh-io/ztm">Flomesh ZTM</a> (Zero Trust Mesh) is an open-source, privacy-first decentralized networking solution that enables secure, seamless connectivity across various networks. It allows you to enforce <strong>Zero Trust security</strong> across your infrastructure, ensuring that only authenticated and authorized devices can communicate within your network. By integrating Flomesh ZTM with <strong>OpenWRT</strong> routers, you can significantly enhance your network’s security and functionality, enabling secure access to internal services without the complexity of traditional VPNs or firewall setups.</p><p>This guide will walk you through how to set up the <strong>Flomesh ZTM agent</strong> on OpenWRT and connect it securely to a <strong>Flomesh ZTM Hub</strong>. The ZTM Hub can either be deployed on AWS using a pre-configured AMI or installed manually on your own machine.</p><h4><strong>Why Use Flomesh ZTM with OpenWRT?</strong></h4><p>OpenWRT, a highly flexible and customizable open-source router firmware, provides the ideal foundation for integrating Flomesh ZTM. By combining these two technologies, you get several key benefits:</p><ul><li><strong>Secure Remote Access</strong>: ZTM enables secure, encrypted communication for devices behind NATs or firewalls, allowing remote access to internal services without exposing them directly to the internet.</li><li><strong>Zero Trust Security</strong>: ZTM ensures that every device, user, and application is verified before any connection is allowed, significantly enhancing your network’s security posture.</li><li><strong>Service Discovery and Load Balancing</strong>: ZTM automatically discovers services in your network and balances the load, making your infrastructure more efficient and resilient.</li><li><strong>TLS-Encrypted Communication</strong>: All traffic between devices is encrypted, ensuring privacy and integrity of data across the network.</li><li><strong>Simplified Network Management</strong>: ZTM eliminates the need for complex VPN configurations or port forwarding, making it easier to manage remote access securely.</li></ul><h4><strong>Step-by-Step Guide: Setting Up ZTM on OpenWRT</strong></h4><h4><strong>1. Install the ZTM Package on OpenWRT</strong></h4><p>To integrate Flomesh ZTM with your OpenWRT device, follow these steps to install the ZTM agent:</p><ol><li><strong>Download the ZTM Package</strong>:</li></ol><ul><li>Visit the <a href="https://github.com/flomesh-io/openwrt-ztm/releases">Flomesh OpenWRT ZTM Releases</a> page to download the appropriate package for your OpenWRT device.</li></ul><ol><li><strong>Transfer the Package to OpenWRT</strong>:</li></ol><ul><li>Use SCP, FTP, or any file transfer method to copy the package to your OpenWRT device.</li></ul><ol><li><strong>Install the Package</strong>:</li></ol><ul><li>SSH into your OpenWRT device and use either opkg or apk (depending on your system) to install the package.</li></ul><ol><li>For opkg:</li></ol><ul><li>opkg install /path/to/ztm-package.ipk</li></ul><ol><li>For apk:</li></ol><ul><li>apk add --allow-untrusted /path/to/ztm-package.apk</li></ul><ol><li>Replace /path/to/ztm-package.ipk with the actual path of the downloaded package.</li><li><strong>Start the ZTM Service</strong>:</li></ol><ul><li>To start the ZTM agent, use the following command:</li><li>/etc/init.d/ztm_agent.init start</li></ul><ol><li><strong>Enable ZTM Service on Boot</strong>:</li></ol><ul><li>To ensure that the ZTM agent starts automatically on boot, run:</li><li>/etc/init.d/ztm_agent.init enable</li></ul><h4><strong>2. Connect the ZTM Agent to the ZTM Hub</strong></h4><p>After successfully installing the ZTM agent on your OpenWRT device, it’s time to connect it to a <strong>Flomesh ZTM Hub</strong>. The ZTM Hub can be set up on AWS using the Flomesh ZTM AMI or installed on your own machine.</p><h4><strong>Option 1: Setting Up the ZTM Hub on AWS (Using the Flomesh AMI)</strong></h4><ol><li><strong>Launch the ZTM Hub AMI on AWS</strong>:</li></ol><ul><li>Go to the <a href="https://aws.amazon.com/marketplace/search/results?searchTerms=ztm">Flomesh ZTM AMI on AWS Marketplace</a> and launch the AMI. Follow the instructions to configure and launch your instance.</li><li>You’ll need to choose the correct instance type, configure security groups, and select an SSH key pair.</li></ul><ol><li><strong>Retrieve the ZTM Root Permit</strong>:</li></ol><ul><li>Upon the first boot of your instance, a ztm-permit.json file will be generated in the /root/.ztm directory. This permit file is required to connect your ZTM agent to the ZTM Hub.</li><li>SSH into the instance and retrieve the permit file:</li><li>cat /root/.ztm/ztm-permit.json</li></ul><ol><li><strong>Save the Permit File</strong>:</li></ol><ul><li>Copy the contents of the ztm-permit.json file. You will need this file when configuring the ZTM agent on OpenWRT.</li></ul><h4><strong>Option 2: Setting Up the ZTM Hub Locally</strong></h4><p>If you prefer to set up the <strong>ZTM Hub</strong> on your own machine or server instead of using AWS, you can follow the official <a href="https://github.com/flomesh-io/ztm/wiki">Flomesh ZTM documentation</a> to install the ZTM Hub on a local instance (Linux, Docker, etc.).</p><h4><strong>3. Configure the ZTM Agent on OpenWRT</strong></h4><p>Now that you have the <strong>ZTM Hub</strong> set up (either on AWS or locally), it’s time to connect your OpenWRT device to it:</p><ol><li><strong>Obtain the </strong><strong>ztm-permit.json File</strong>:</li></ol><ul><li>Copy the ztm-permit.json file you retrieved earlier from the ZTM Hub instance.</li></ul><ol><li><strong>Configure the ZTM Agent</strong>:</li></ol><ul><li>On your OpenWRT device, configure the ZTM agent to use the ztm-permit.json file to authenticate and connect to the ZTM Hub. Replace localhost:7777 with the IP address of your OpenWRT device.</li></ul><ol><li>The command should look like this:</li></ol><ul><li>ztm join MESH_NAME --as EP_NAME --permit /path/to/ztm-permit.json</li><li><strong>MESH_NAME</strong>: This is the name of the mesh you want to join locally. It can be any name you choose.</li><li><strong>EP_NAME</strong>: This is the name of your endpoint that will be visible to other endpoints in the mesh.</li><li><strong>/path/to/ztm-permit.json</strong>: This is the path to the permit file you retrieved earlier.</li></ul><h4><strong>Common Use Cases with ZTM on OpenWRT</strong></h4><p>With Flomesh ZTM integrated into your OpenWRT router, you can now securely access internal services, set up proxies, and enable secure remote connections:</p><ol><li><strong>Secure Internal Services</strong>:</li></ol><ul><li>Expose services like web servers or file-sharing tools to the outside world securely, without requiring complex port forwarding or VPN setups.</li></ul><ol><li><strong>Set Up a Secure Proxy</strong>:</li></ol><ul><li>Use ZTM to route traffic securely between external clients and internal services, without exposing those services directly to the internet.</li></ul><ol><li><strong>Remote Desktop Access</strong>:</li></ol><ul><li>Configure ZTM to access remote desktop services securely within your network, allowing you to manage devices remotely.</li></ul><ol><li><strong>Point-to-Site VPN Alternative</strong>:</li></ol><ul><li>Although ZTM isn’t a direct replacement for traditional VPNs, it offers a lightweight and secure alternative to accessing internal resources without needing a full VPN setup.</li></ul><h4><strong>Using Your ZTM Mesh</strong></h4><p>After connecting your OpenWRT devices to the <strong>ZTM Hub</strong>, you can manage your mesh effectively:</p><ul><li><strong>Tunnel</strong>: Establish secure TCP/UDP tunnels between endpoints.</li><li><strong>Proxy</strong>: A SOCKS/HTTP forward proxy that routes traffic from one endpoint to another.</li><li><strong>Script</strong>: Execute PipyJS scripts remotely on an endpoint.</li><li><strong>Terminal</strong>: Remote access to the shell on an endpoint.</li></ul><p>You can interact with your mesh via both <strong>CLI</strong> and <strong>GUI</strong>:</p><ul><li>If you prefer <strong>GUI</strong>, open your browser and point it to http://&lt;OpenWRT-IP&gt;:7777. You can join a mesh, find other endpoints, and manage applications directly from the browser. Almost all functionalities ZTM provides are available through both the CLI and the GUI.</li></ul><p>Repeat the procedure for every endpoint you want to add to your mesh. Once completed, you’ll be able to manage your mesh via either the terminal or browser from any endpoint in the mesh.</p><p>To view and manage your mesh, use the following commands:</p><ul><li><strong>Check mesh status</strong>:</li><li>ztm get mesh</li><li><strong>List all endpoints</strong>:</li><li>ztm get ep</li></ul><h4><strong>Additional Resources</strong></h4><p>For advanced configurations and additional details, refer to the official <a href="https://github.com/flomesh-io/ztm/wiki">ZTM Wiki</a>. The wiki provides extensive documentation on setting up proxies, accessing remote desktops, and more.</p><p>By using <a href="https://github.com/flomesh-io/ztm">Flomesh ZTM</a> with <a href="https://openwrt.org">OpenWRT</a>, you can effortlessly integrate <strong>Zero Trust</strong> security across your network, providing secure access to internal services without the overhead of traditional VPN solutions. This combination is ideal for home labs, small businesses, or anyone looking to enhance their network security with minimal complexity.</p><img alt="" height="1" src="https://medium.com/_/stat?event=post.clientViewed&amp;referrerSource=full_rss&amp;postId=d2f6f6777e0a" width="1" /><hr /><p><a href="https://blog.flomesh.io/set-up-openwrt-for-effortless-secure-remote-access-to-all-your-devices-no-vpn-needed-d2f6f6777e0a">Set Up OpenWRT for Effortless, Secure Remote Access to All Your Devices — No VPN Needed</a> was originally published in <a href="https://blog.flomesh.io">Flomesh</a> on Medium, where people are continuing the conversation by highlighting and responding to this story.</p>
